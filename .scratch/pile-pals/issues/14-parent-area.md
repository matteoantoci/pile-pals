# 14: Parent area

Spec: [spec.md](../spec.md)

**What to build:** The Parent holds the logo for 3 seconds and answers a multiplication problem. The parent area then gives credits, export, restore, reset, and a sound switch.

**Blocked by:** 09 (Save, restore, and the shell), 10 (Title scene), 13 (Pal sounds)

**Status:** ready-for-agent

- [ ] A 3-second hold on the logo shows a multiplication problem with factors from 3 to 9 and a digit pad.
- [ ] A new problem shows each time. A wrong answer closes the check.
- [ ] The parent area uses English text.
- [ ] Export gives a save code. Restore from a save code gives the same game.
- [ ] Reset deletes all game data after a confirmation.
- [ ] Sound effects can be turned on or off.
- [ ] The credits list Noto Animated (CC BY 4.0), Noto 2D (Apache 2.0), each CC BY sound, and each CC0 source.
